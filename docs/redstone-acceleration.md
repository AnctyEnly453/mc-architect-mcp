# 红石加速

MC Engineer 0.8 提供可关闭的独立红石时钟和粉线网络优化。世界、实体、流体仍按原来的游戏 tick 运行。默认不开启，退出世界后不会自动开启。

游戏内需要作弊/游戏管理权限：

```text
/mcengineer redstone 128 8
/mcengineer redstone status
/mcengineer redstone off
```

第一个数字是每个游戏 tick 最多执行多少个红石子步（1–256），第二个数字是工作线程数（1–16，可省略）。默认预留两个逻辑处理器、最多使用 8 个工作线程。命令使用每游戏 tick 20ms 的软预算；达到预算后会少跑几个子步，未执行的事件保留到下一次。单次原版方块更新无法中途抢占，因此某次工作耗时可能超过预算。倍率是上限，`status` 中的实测速率才代表实际吞吐量。

MCP 工具 `mc_redstone` 提供 `configure`、`status`、`disable`，可设置 `speed`、`workers`、`budgetMs`（1–40）和 `optimizeWires`。命令行入口：

```powershell
$env:MCA_CONFIG='D:/MinecraftInstance/config/mcarchitect.json'
cd D:/minecraft/mc-architect-mcp/bridge
node scripts/redstone.mjs configure 128 8 20 true
node scripts/redstone.mjs status
node scripts/redstone.mjs disable
```

HTTP 接口为认证后的 `POST /v2/redstone`，参数与工具一致。`mc_world save` / `POST /v1/save-world` 保存当前世界并保持打开。

## 实现和兼容边界

中继器、比较器、红石火把、红石灯、按钮和侦测器的计划事件使用独立时钟。延迟数值、事件优先级和次序仍由原版组件决定。火把烧毁/冷却使用同一红石时钟。活塞等其他执行器仍按世界 tick 更新，不承诺高倍率下所有机械装置与原版等价。

粉线缓存为有向网络；上台阶、下台阶和信号衰减按原版取输入规则建立。主线程采集外部输入，工作线程只运行不可变整数数组上的传播计算，结果统一回到主线程写入。小任务在主线程计算，避免线程切换开销。独立网络足够多时才提交并行任务，因此不能保证所有 CPU 核心始终满载；串行电路仍有依赖关系。

网络一次性求稳定信号会消除某些原版更新过程中的瞬态。依赖更新顺序、瞬态脉冲的线路应先验证；可设置 `optimizeWires:false` 保留原版粉线传播并只使用独立红石时钟，或关闭整个加速模式。超过网络大小上限的粉线回退原版计算。

存档保存前，待执行红石事件转回原版区块队列，以正常的剩余延迟保存；保存完成后重新接管。区块卸载也先交还该区块的队列。关闭加速时同样交还队列。不会给存档留下必须依赖 Mod 私有文件才能恢复的红石计划事件。

施工前须关闭加速。红石测试执行期间不能切换时钟；先结束或取消测试。加速模式下测试套件的 tick 指红石逻辑子步，输入、采样和延迟使用同一时钟。测试结束仍恢复操作杆/按钮，不回滚 CPU 内部存储。

## 实测

测试对象为实体十六进制键盘、8×11 位 RAM、8 位 CPU 和字符灯阵组成的计算机。程序：`IN; ADDI 1; OUT; LDI 37; ADDI 19; ADDI 8; OUT; HLT`。每轮运行 48,000 个逻辑 tick，93 项断言全部通过，最终输出为十进制 64，显示数字 `40` 并停机。

| 设置 | 测试耗时 | 平均逻辑步/秒 |
|---|---:|---:|
| 128 子步、原版粉线传播 | 46.137 秒 | 1,040 |
| 128 子步、网络优化、8 工作线程 | 22.853 秒 | 2,100 |

两轮世界均为 20 tick/秒、软预算 20ms。网络优化在这次对照中约快 2.02 倍。完整加速相对 20 tick/秒的时间基准约 105 倍，相对先前 80 tick/秒约 26 倍；实际倍率取决于电路、区块负载和硬件。计时包含测试运行和结果完成的短暂收尾，不含前期加载；不是纯工作线程的基准。

上述数据来自开发存档的实测，测试存档与原始录制文件不随本仓库分发。优化轮记录了 156 次并行批次、624 个工作线程任务；主线程方块查询和写回仍占用计算时间。

0.8.0 安装包的额外保存测试：第 8,706 步、仍有 13 个待执行事件时执行世界保存，随后继续完成全部 93 项检查，耗时 23.053 秒。期间世界只推进了约 500 个游戏 tick。
